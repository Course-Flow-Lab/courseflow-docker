# 更新与回退

获取最新正式镜像：

```sh
git pull --ff-only
./scripts/courseflow update latest
```

该命令每次重新拉取 API 与 WebUI 的 `latest` 标签，核对两个镜像的发布版本相同，并在部署配置与容器中保留字面量 `:latest` 引用，不解析为 digest 或版本标签。API 和验证码服务均使用 `courseflow-api:latest`，网页使用 `courseflow-webui:latest`；Compose 的默认拉取策略为 `always`。标签切换期间若版本不一致，会在停止当前服务之前退出，可稍后重试；拉取失败不会影响当前服务。

v0.1.11 配套 Framework 0.1.20、WebUI 0.1.8、ZHS 0.3.16 和超星 0.1.10。网页验证码支持实时拖动反馈及管理员独立测试；模型答案格式不合法时只重试一次，资料不足仍要求人工补答。北京时间 23:00–07:00 对所有账号全局停止后台保活，不受个人任务偏好影响。超星对目录未完成但保留历史交卷的任务先只读核对原答卷，只有官方明确证明同一答卷仍可提交才继续，未知状态不重发。

超星 0.1.10 声明兼容 0.1.2–0.1.9 检查点；升级后暂停任务需在详情中显式迁移后继续。保留原数据库、主密钥、模块配置和交卷记录，不自动恢复真实任务。ZHS 本轮仅更新发布说明，仍为 0.3.16。

v0.1.10 配套 Framework 0.1.18、WebUI 0.1.5、ZHS 0.3.16 和超星 0.1.9。智慧树改用官方共享课验证码组件，自动验证需要人工接续时，可直接在任务弹窗查看并操作验证码；平台拒绝后会重新打开新题。超星可选择待解锁章节及其前置任务，按章节顺序接续学习；自动提交前置测验由创建任务时的选项控制，响应丢失时先核对平台结果，待确认期间继续其他可学内容。

ZHS 声明兼容 0.3.8–0.3.15 的检查点，超星声明兼容 0.1.2–0.1.8。升级后在任务详情查看迁移入口，按提示迁移并继续；交卷待确认的任务先核对结果。可选模块 U校园 0.5.1 复用宿主题库，要求 Framework >=0.1.6；QLTeacher 0.2.4 以平台回读进度及实际经过时间上报视频，平台拒绝计时后等待并重试一次。这两个模块需要从模块下载页另行安装；请按任务页面提示处理旧任务。

v0.1.9 配套 Framework 0.1.14、WebUI 0.1.4 和 ZHS 0.3.9。已有智慧树 0.3.8 的暂停任务可在「任务中心 → 任务详情」点击「迁移到 0.3.9」，再点击「继续」。任务仍使用原账号、进度和检查点。交卷结果待核对时先回读结果。其他模块须在清单声明旧版本的检查点兼容性。

v0.1.8 配套 Framework 0.1.13、WebUI 0.1.3、ZHS 0.3.8。团队角色可在一个站点管理多个平台账号，并使用跨平台总配额。新增内部验证码容器，共享课学习支持拼图识别、官方令牌确认和重新计时。此版本会将数据库从 3 升级到 4；更新工具先备份数据库、主密钥与模块，回退到旧后端需整体恢复配对备份。原有用户、连接和任务保留；ZHS 模块版本变化后请新建学习任务。

v0.1.7 更新 Framework 至 0.1.11、WebUI 至 0.1.2。全站任务默认按最近更新排序，可切换创建时间和执行状态；管理员可删除本站任务记录，执行中任务先停止，未核对的交卷结果先回读。课程首次读取目录即显示完成度，并同步回课程卡片；部分未知状态保留完成数量，尚未读取的目录提示「进入课程后读取」。平台模块、数据库版本、现有作答和主密钥不变。

v0.1.6 更新智慧树至 0.3.7，修复实际作业将题型放在 `questionType: {id, name}` 对象中时，所有题目都被误标为不支持的问题；保存答案时使用数字题型编号。经授权在 localhost 实际账号中验证了五题作业的模型作答、草稿保存和平台回读，停在交卷确认，未交卷。Framework 0.1.10 和 WebUI 0.1.1 保持原提交。仅当从更早的模块版本升级时，需要新建作业任务重新读取题型；已在平台保存的草稿会读取并保留。

v0.1.5 更新 Framework 至 0.1.10，修复模型选项标签被 `DNA` 等选项正文抢先匹配，导致正确多选答案被当成重复选项的问题；同时兼容紧凑及分隔的多选标签，补答提示包含当前题号。WebUI 0.1.1 和智慧树 0.3.6 保持原提交。从 v0.1.4 升级到 v0.1.5 后，仍在有效期内、因模型答案格式暂停的作业任务可点击「继续」，沿用原作答，不重复开卷，并保留原有交卷确认设置。

v0.1.4 包含 Framework 0.1.9、WebUI 0.1.1 和智慧树 0.3.6，修正共享课作业读取已有答案及普通小节误传子视频编号的问题，并将短时试跑限定为管理员诊断入口。若从更早版本升级导致平台模块版本变化，旧任务会提示重新创建；请重新选择未完成单元创建学习任务。

从一个明确的 GitHub Release 下载并核对 `images.lock.env` 和 SHA256SUMS；同时更新本部署仓库或使用该版本的部署包。

```sh
./scripts/courseflow update /发布包/images.lock.env
```

顺序为：拉取/检查新镜像 → 停止 API → 一致备份并验证 → 更新内置模块（仅源码提交改变时，保留设置和启用状态）→ 应用新部署配置 → 等待 API、Web 与验证码容器健康。额外安装的平台模块保留。更新失败时尝试恢复已验证的配对快照，再检查服务；`latest` 模式下不保证回到旧镜像版本，软件版本回退须显式选择对应 Release 的固定锁文件。

默认部署始终使用 `:latest`；`up` 与 `update latest` 会主动拉取并检查镜像，直接执行 Compose 启动时也会按 `pull_policy: always` 拉取。单纯重启已存在的容器不会下载镜像，工具不在后台自动更新或删除镜像。`latest` 可变，因此恢复备份不会把标签指回旧镜像；需要恢复特定软件版本时，另行选择对应 Release 的固定锁文件。`sources.lock.json` 和 `release.json` 保留源码、镜像 ID 与 digest 的来源记录，不改变在线默认部署的 `:latest` 引用。

已完成的更新若需人工回退，使用 `restore`。还原后核对账号、模块和课程任务状态，手动恢复需要继续的暂停任务。
